# OrangeHRM Manual Testing Project

## Project Overview
This project demonstrates manual functional testing of the OrangeHRM demo application. The objective is to verify key application workflows, including login, employee search, and employee management, by comparing actual application behaviour with expected results.

## Application Tested
- **Application:** OrangeHRM Demo
- **Testing Type:** Manual Functional Testing
- **Test Environment:** Web Browser
- **Documentation Tool:** Microsoft Excel

## Testing Scope
The following application workflows were tested:

1. **Login:** Verify login with valid credentials.
2. **Employee List:** Verify that the employee list loads correctly.
3. **Employee Search:** Search for existing and non-existing employee IDs.
4. **Search Reset:** Verify that search fields are cleared after using Reset.
5. **Add Employee:** Verify the employee form and its available fields.
6. **Mandatory Field Validation:** Check validation when required fields are left blank.
7. **Cancel Functionality:** Verify that cancelling the add-employee form does not create a record.
8. **Employee Creation:** Create a test employee using valid information.
9. **Employee Search Verification:** Search for the newly created test employee.

## Project Outcome
This exercise provided practical exposure to manual testing workflows, test case documentation, functional validation, and recording test execution results.

## Scope and Limitations
This was an independent practice project conducted on a publicly accessible demo application. The testing was limited to the workflows documented in the accompanying test cases. No access to OrangeHRM's internal database or proprietary Wipro systems was used.
